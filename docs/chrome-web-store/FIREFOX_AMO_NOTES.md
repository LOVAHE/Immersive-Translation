# Firefox AMO Notes

## Proposed Name

Adaptive Translation

## Summary

Translate selected text, pages, captions, images, and PDFs inline using a provider selected by the user.

## Compatibility Notes

- Firefox uses `manifest.firefox.json`.
- Firefox Manifest V3 uses `background.scripts` for the background context. Chrome uses `background.service_worker`.
- The Firefox package does not request the Chrome-only `offscreen` permission.
- Chrome AI local provider is treated as Chrome-only. It should not be advertised for the Firefox listing.
- The package is generated by `tools/build-firefox.ps1`.

## Suggested AMO Categories

- Language Support
- Productivity

## Suggested Testing Instructions

1. Install the submitted add-on.
2. Open the options page.
3. Configure a translation provider API key.
4. Select text on a normal webpage and use the context menu to translate.
5. Use the context menu to translate a full page.
6. Optional: test image/PDF OCR if the selected provider supports the configured flow.

## Review Risk Areas

- Broad `<all_urls>` content script access.
- Broad `https://*/v1/*` custom OpenAI-compatible endpoint permission.
- Sending user-requested page/selection/OCR content to third-party translation providers.
