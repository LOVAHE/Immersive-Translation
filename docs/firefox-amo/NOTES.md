# Firefox AMO Notes

## Upload Package

Use the generated `.xpi` file in `dist/`:

`adaptive-translation-firefox-3.2.0-*.xpi`

## Proposed Name

Adaptive Translation

## Summary

Translate selected text, pages, captions, images, and PDFs inline using a provider selected by the user.

## Compatibility Notes

- Firefox uses `manifest.firefox.json`.
- Firefox Manifest V3 uses `background.scripts` for the background context.
- The Firefox package does not request the Chrome-only `offscreen` permission.
- The manifest declares required `data_collection_permissions` for `authenticationInfo` and `websiteContent` because user-provided API credentials and user-requested translation content may be transmitted to the selected translation provider.
- Chrome AI local provider is Chrome-only and should not be advertised for Firefox.
- The experimental Codex provider is shown as unavailable in Firefox and the Firefox manifest does not request `nativeMessaging`. It never falls back silently to another provider.
- The package is generated by `tools/build-firefox.ps1`.

## Suggested AMO Categories

- Language Support
- Productivity

## Suggested Testing Instructions

1. Install the submitted add-on.
2. Open the options page.
3. Configure a translation provider API key.
4. Select text on a normal webpage and use the context menu to translate.
5. Use the context menu to translate a full page.
6. Optional: test image/PDF OCR if the selected provider supports the configured flow.

## Reviewer Notes

The add-on bundles PDF.js and the Tesseract.js runtime locally for PDF parsing and OCR. These third-party bundled files may trigger validator warnings related to `Function` or dynamic imports. OCR language data is downloaded from jsDelivr as needed; executable extension code is not downloaded at runtime.

Dynamic `import()` calls are used to load extension-bundled modules from `browser.runtime.getURL(...)`, such as image translation and PDF/OCR helpers, only when the user triggers those features.

## Review Risk Areas

- Broad `<all_urls>` content script access.
- Broad `https://*/v1/*` custom OpenAI-compatible endpoint permission.
- Sending user-requested page/selection/OCR content to third-party translation providers.
