## Summary

Code health improved in one selected scope: three provider-specific copies of
dictionary response normalization are now one documented helper, protected by
six tests that preserve each provider's distinct parse-failure fallback.

The repository as a whole is not release-ready. Prompt override semantics,
content-bearing logs, provider capability routing, settings defaults, YouTube
lifecycles, and generated release identity all have concrete evidence-backed
follow-up. Current `dist/` entries predate this repair and must not be treated as
release candidates.
